| Role | Typeface | Weights | Used for |
| --- | --- | --- | --- |
| Display | [Bricolage Grotesque](https://fonts.google.com/specimen/Bricolage+Grotesque) | 700 to 800 | Headings, titles, anything that should have a bit of swagger |
| Body | [Inter](https://fonts.google.com/specimen/Inter) | 400 and 600 | Paragraphs, captions, interface text |
| Mono | [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) | 400 and 600 | Code, commands, and small uppercase labels |

All three are free under the SIL Open Font License. The font files are in the `fonts/` folder of this repository, and they're on Google Fonts and Fontsource:

```sh
npm install @fontsource-variable/bricolage-grotesque @fontsource-variable/inter @fontsource-variable/jetbrains-mono
```

## Setting it

- Track display text tight, about −0.02em for headings and −0.03em for big titles.
- Set uppercase mono labels loose, about +0.14em.
- Turn off code ligatures (`font-variant-ligatures: none`), so `::` and `=>` look like what you type.

## Social template sizes

On a 1280 × 640 card:

| Element | Typeface | Size | Colour |
| --- | --- | --- | --- |
| Kicker | JetBrains Mono 600, uppercase | 22px | Template 300 |
| Title | Bricolage Grotesque 800 | 84px, smaller for long names | Paper |
| Tagline | Inter 400 | 29px | Slate 300 |
| Command | JetBrains Mono 600 | 19px | Ink on template 300 |
