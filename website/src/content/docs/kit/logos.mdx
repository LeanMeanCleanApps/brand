Every mark comes in the same set of files, in `assets/logos/<mark>/`:

| Folder | What's in it |
| --- | --- |
| `svg/` | Vector files. Use these wherever SVG is accepted. |
| `png/` | Pixel files from 16 to 1024 pixels. Sizes of 48 and below use the small version. |
| `web/` | Ready-made website icons: `favicon.svg`, `favicon.ico`, `apple-touch-icon.png` and web manifest icons. |

File names follow `<mark>[-small][-variant][-size]`:

| Variant | Background | Best for |
| --- | --- | --- |
| _(none)_ | Transparent, for dark backgrounds | Docs site headers in dark mode, slides, video |
| `-light` | Transparent, for light backgrounds | Docs site headers in light mode, print on white |
| `-tile` | Ink rounded square | App icons, favicons, cards |
| `-square` | Ink square, edge to edge | Avatars on platforms that crop or round corners themselves |
| `-circle` | Ink circle | Stickers, round badges |
| `-layered` | Ink rounded square, one named layer per ring | Editing in Inkscape, Figma or Illustrator |

The single-colour versions are in `assets/logos/mono/`, in ink and in paper, for print, embossing and watermarks. Also for the one printer in every office that only does black.
